A tiny household tool

Copy Woolworths shopping lists from one account to another

Three bookmarklets that run in your own browser, on pages you're already logged into. Nothing here ever sees or handles a password — it just does, on your behalf, what you'd otherwise click through by hand.

How this works, in one sentence

Each bookmarklet is a little script that runs on the current Woolworths tab when you click it — one reads your lists off the page, one bundles them into a file, and one reads that file back in on the other account and rebuilds the lists there.

Install the three bookmarklets

Show your bookmarks bar (Ctrl/Cmd + Shift + B), then drag each button below onto it.

☑ 1. Export this list
⬇ 2. Download export
⬆ 3. Import lists

Use them

  1. Export, one list at a time

    On the account whose lists you want to copy from, open My Lists, click into a list, then click 1. Export this list. Repeat for every list you want — each click adds that list to a running collection saved in this browser, so it doesn't matter what order you do them in or if you close the tab in between.

  2. Download the collection

    Once you've exported everything you want, click 2. Download export on any Woolworths page. It bundles everything you've collected into one woolworths-lists-export.json file and asks if you want to clear the saved copy afterwards.

  3. Import into the other account

    Log into the account you want to copy into, go to My Lists, and click 3. Import lists. Pick the JSON file from step 2. It'll create each list and add its items one by one, showing progress in the corner — leave the tab open and don't click away until it's done.

Before you run this on real lists

Test the import with one small list first and check the result before importing everything else. A few things worth knowing:

It's safe to re-run — lists and items that already exist by name are skipped rather than duplicated, so if it gets interrupted partway through, just click the bookmark again.

Adding an item works by typing its name into Woolworths' own "Add to this list" search box and picking the first suggestion — same as you would by hand. For oddly-named items that might not be the exact product you meant, so it's worth a glance over the finished list.

Woolworths can change their site's layout at any time, which could stop one of these working. If a bookmarklet stops finding things, the README has notes on how to fix it.

Privacy

Everything happens locally in your browser. The export data lives in that browser's localStorage until you download or clear it, and the download itself is a plain JSON file that goes wherever your browser saves downloads — it isn't sent anywhere else. This page doesn't run any script of its own beyond what's shown here; it's just the install point for the bookmarklets.
